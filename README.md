# hadiahmed.com

Hadi Ahmed's personal site and blog, built with [Astro](https://astro.build). Every page is a static file, and the site deploys to GitHub Pages whenever `main` changes. Posts are Markdown files in `src/content/posts/`. You can add them with the Pages CMS editor (see `docs/how-to-post.md`) or directly on GitHub.

| Command | What it does |
|---|---|
| `npm run dev` | Local preview at http://localhost:4321/hadiahmed.com/ |
| `npm test` | Unit tests |
| `npm run build` | Type-check and build into `dist/` |
| `npm run test:e2e` | Browser and accessibility tests against the built site |
| `npm run check:all` | Everything above |
