A self-directed project to learn how cloud monitoring works in practice.

I built a serverless monitoring automation on Microsoft Azure using Azure Functions. PowerShell scripts run on a schedule, generate infrastructure health reports, and log the results through Azure Application Insights.

What I took away from it: how scheduled, serverless jobs fit together, and how much easier it is to trust a system when its health is written down somewhere you can check.
